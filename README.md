# Tuperno – Landing Page 

##  Descripción general

Este repositorio contiene el desarrollo de una **landing page para la empresa Tuperno**, creada con fines **académicos y de portafolio personal** durante mi práctica profesional.

El proyecto tiene como objetivo presentar la empresa, sus servicios y una propuesta visual moderna, aplicando buenas prácticas de **desarrollo frontend**, organización de archivos y control de versiones con Git.
